# Segurança

Projeto inicial, sem auditoria externa ou garantias de compatibilidade universal. Leia docs/privacy e docs/platform-support.

Não publique credenciais, textos pessoais ou dumps com segredos em issues. O repositório remoto ainda não foi criado por esta tarefa; antes de publicar, o mantenedor deve ativar um canal de relato privado de vulnerabilidades no GitHub ou definir contato. Enquanto isso, evite divulgação pública de detalhes exploráveis com dados reais.

Relatos úteis: versão, sistema/build, provider/protocolo, comportamento reproduzível com texto fictício e impacto. TLS é validado; não aceite patches que desativem validação, exponham segredos ao frontend, reutilizem cookies/CLIs, habilitem IPC remoto genérico ou executem conteúdo traduzido.
